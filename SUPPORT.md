# Suporte do Cifras Scroll

Use as [issues do repositório](https://github.com/glaysonbsantos/cifras-scroll/issues) para relatar problemas ou tirar dúvidas.

Inclua, quando possível:

- versão do Chrome e sistema operacional;
- versão do Cifras Scroll, disponível em `chrome://extensions`, e origem da instalação (loja ou build local);
- endereço público da página em que o problema ocorreu, se puder ser compartilhado;
- estado exibido no popup;
- passos para reproduzir;
- comportamento esperado e comportamento observado;
- se **Parar agora** ou o atalho liberou a câmera.

Antes de abrir uma issue, consulte os [problemas comuns](docs/INSTALLATION.md#problemas-comuns) e as [limitações conhecidas](docs/KNOWN_LIMITATIONS.md). Há modelos para relatar problemas e sugerir melhorias no formulário de issues.

As issues são públicas. Não anexe vídeo, imagens ou frames da câmera, logs completos nem informações pessoais. Remova tokens, parâmetros privados e dados de contas dos endereços compartilhados. Se o problema ocorrer em uma página privada, descreva o tipo de página ou tente reproduzi-lo em uma página pública.

Para interromper imediatamente uma sessão, use **Parar agora**, o atalho configurado em `chrome://extensions/shortcuts` ou desative a extensão. `PAUS` indica que a câmera continua ligada.

Para sugestões, descreva a situação de uso e a melhoria desejada. Não é necessário usar a câmera nem fornecer dados pessoais para pedir ajuda.
