# Suporte do Cifras Scroll

Use as [issues do repositório](https://github.com/glaysonbsantos/cifras-scroll/issues) para relatar problemas ou tirar dúvidas.

Inclua, quando possível:

- versão do Chrome e sistema operacional;
- página em que o problema ocorreu;
- estado exibido no popup;
- passos para reproduzir;
- se **Parar agora** ou o atalho liberou a câmera.

Não anexe vídeo, imagens ou frames da câmera nem informações pessoais. Para interromper imediatamente uma sessão, use **Parar agora**, o atalho configurado em `chrome://extensions/shortcuts` ou desative a extensão.
